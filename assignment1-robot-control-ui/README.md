# 🧪 Assignment 1: Robot Control UI

## 🎯 Objective

Design and implement a responsive **User Interface** (UI) for controlling a robot using a joystick. The UI must support real-time communication with a backend server and reflect robot movement live on a map.

---

## 📋 Requirements

Your UI must include the following:

1. **Joystick Control Panel**

   - A visual joystick component for direction control.
   - Sends direction or velocity data to the backend.

2. **Live Map View**

   - Shows the robot's real-time position.
   - Receives data from the backend and renders the robot on a map.

3. **Emergency Button**

   - Sends an emergency stop signal to the backend immediately.
   - Clearly visible and styled for high contrast.

4. **Start Button**
   - Sends a start command to begin operation.

---

## 🌐 Technical Requirements

- Should be **responsive** across desktop, tablet, and mobile devices.
- Use any frontend framework/library of your choice (e.g., React, Vue, Svelte, plain HTML/JS).
- Communication with the backend should simulate **real-time** updates.
- Writing how to run the UI in the `README.md` file is mandatory.
